### Tipografia

**Família Tipográfica:** Istok Web
<br>
**Categoria:** Sans-serif (sem serifa)
<br>

A tipografia utilizada no projeto é a Istok Web, uma fonte sans-serif de estilo humanista, conhecida por sua alta legibilidade em ambientes digitais. Ela apresenta formas abertas e equilibradas, sendo adequada para interfaces e textos longos.
